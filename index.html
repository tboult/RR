Random Robin

📖 App Instructions & Help

App Purpose: Generates randomized player court assignments (Servers, Receivers, or Bye) for group pickleball round-robin sessions.

How to Use:

  • #Players: Enter total players present. Calculates needed courts and Bye breaks automatically.
  • Game #: Increments after each round. Tap Reset Game # to set back to 1.
  • Timer (Minutes): Built-in match countdown clock with audio and vibration alerts.
  • Max Courts: Set total courts available at your facility.
  • Select Courts: Check off courts open for play.
  • Select Start Assignments to begin.
  • Tap anywhere on screen to advance to the next player assignment.
  • Offline Use / Home Screen: Tap "📱 Install App" above to save Random Robin directly to your phone for quick offline access!
